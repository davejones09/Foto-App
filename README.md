# Nahtlos

Foto-Web-App fürs iPhone: Jedes Foto beginnt dort, wo das letzte aufhört. Aus einer ganzen Reise wird ein einziges, durchgehendes Bild.

- Läuft als Home-Bildschirm-App aus GitHub Pages, komplett offline, alle Fotos bleiben auf dem Gerät.
- Konzept, Technik und Etappen stehen in `docs/`.
- Tests: `npm test` (ohne Browser) und `npm run test:browser` (Chromium mit Kamera-Ersatz).
